Mapping Cellular Dynamics in Bladder Tissue

A specialized computational model and analysis framework designed by hsouporto for investigating urothelial cell phenotypes, gene expression profiles, and structural biology.

Get Started Explore Interactive Model

Project Overview

Cello-Bladder-Cell bridges computational modeling with high-throughput single-cell RNA sequencing (scRNA-seq) analysis specifically optimized for urothelial tissues.

Transcriptomic Pipeline

Robust preprocessing, normalization, and dimensional reduction pipelines designed to handle noisy single-cell bladder tissue datasets.

Cell Clustering & Annotation

Automated marker gene detection algorithms to accurately classify umbrella cells, intermediate cells, and basal urothelial cell types.

Extensible Architecture

Modular Python package structure enabling researchers to plug in custom clustering models or visualization plugins with ease.

System Architecture

Engineered for Precision and Reproducibility

The codebase is organized into discrete functional modules ensuring end-to-end traceability from raw count matrices to publication-ready UMAP projections and differential expression reports.

  • Data Ingestion: Supports 10x Genomics HDF5 formats and standard CSV/TSV expression matrices.
  • Quality Control Filters: Automatic outlier removal based on mitochondrial gene percentage and library size metrics.
  • Visual Export: High-resolution vector graphic exports for publication figures.

Quick Start Installation

Clone the repository from hsouporto and execute the analysis pipeline.

1. Clone & Install Dependencies 
git clone https://github.com/hsouporto/Cello-Bladder-Cell.git
cd Cello-Bladder-Cell
pip install -r requirements.txt
2. Run Preprocessing & Clustering Pipeline 
python src/preprocessing.py --input data/raw_counts.h5 --output data/processed/
python src/clustering.py --config configs/default.yaml
