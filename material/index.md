## Overview
**Cello-Bladder-Cell** is an open-source repository dedicated to analyzing, clustering, and profiling cellular phenotypes within bladder tissue. This project leverages single-cell genomic data pipelines to investigate cell subpopulations (such as umbrella cells, intermediate cells, basal cells, and stromal/immune components).
